# Protocol Subset

Sound is a hub client. Set `ORCHESTRATOR_REPO` to an Orchestrator checkout and read `$ORCHESTRATOR_REPO/schemas/protocol/envelope.schema.json` and `$ORCHESTRATOR_REPO/schemas/protocol/event-data.schema.json`. Sound handles its RTP L16 media and `media.stream.command` or `media.stream.state` subset. It does not copy schemas or fixtures.
